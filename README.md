# Škoda Kodiaq microsite

Prodejní microsite ve Vite s fotografiemi exteriéru a interiéru.

## Lokální spuštění

```sh
npm ci
npm run dev
```

## Vercel

Kořen projektu je kořen repozitáře. Framework Vite, build `npm run build`, výstup `dist`. Konfiguraci obsahuje `vercel.json`.

## Úpravy

Texty a pořadí galerie: `src/main.js`. Vzhled: `src/style.css`.
Před dokončením inzerátu doplnit telefon nebo e-mail a detailní fotografii poškození pravého předního blatníku.
